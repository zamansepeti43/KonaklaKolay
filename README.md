# KonaklaKolay

Telefon uyumlu dijital misafir rehberi prototipi.

## Özellikler
- Otel bilgilerini düzenleme paneli
- Bilgileri tarayıcının localStorage alanına kaydetme
- Türkçe / İngilizce arayüz
- Wi-Fi bilgisi, kahvaltı ve giriş-çıkış saatleri
- Harita ve WhatsApp bağlantıları
- Sayfa adresi için QR kod üretimi

## GitHub Pages ile yayımlama
1. GitHub deposunda **Settings → Pages** bölümünü açın.
2. **Deploy from a branch** seçeneğini seçin.
3. Branch: `main`, folder: `/(root)` seçip **Save** düğmesine basın.
4. Birkaç dakika sonra `https://zamansepeti43.github.io/KonaklaKolay/` adresini açın.

## Demo sınırları
- Yönetim paneli yalnızca aynı tarayıcıda saklama yapar; giriş/şifre koruması ve sunucu veritabanı yoktur.
- Misafir sayfası ve yönetim paneli aynı sayfada olduğu için bu sürüm gerçek müşteri verileriyle güvenli kullanım için hazır değildir.
- QR kodu üretimi harici bir QR hizmetini kullanır ve sayfa yayımlandıktan sonra kullanılmalıdır.
- Otel bilgileri örnektir. Gerçek işletmeye teslim etmeden önce bilgileri değiştirip tüm bağlantıları test edin.
